## Image Specifications

- **Format**: JPG or PNG
- **Resolution**: Minimum 1920x1080 (preferably 4K: 3840x2160)
- **Aspect Ratio**: 16:9 landscape
- **Color Space**: sRGB
- **File Size**: Optimize for web (< 2MB per image)

## License Notes

Ensure all images are:

1. Public domain (CC0)
2. Creative Commons Attribution (CC BY)
3. Properly licensed for documentary use
4. Credited in video where required

